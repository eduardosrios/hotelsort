# Code of Conduct

## Purpose

Hotelsort is maintained as a professional project. Participation in this repository should stay respectful, constructive, and focused on improving the project.

## Expected Behavior

- Communicate with clarity and respect.
- Keep discussions focused on the project.
- Give actionable feedback when reviewing work.
- Respect ownership, confidentiality, and intellectual property.
- Report security concerns privately through the process described in the security policy.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Submitting content that violates third-party rights.
- Using issues, discussions, or pull requests for spam or unrelated promotion.
- Attempting to bypass the proprietary license or project ownership terms.

## Enforcement

The project owner may edit, hide, reject, or remove contributions and comments that violate this code. Repeated or serious violations may lead to blocked participation in the repository.

## Contact

For conduct concerns, contact the repository owner through GitHub.
