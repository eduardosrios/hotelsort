# Contributing

## Project Status

Hotelsort is a proprietary project. Contributions are accepted only when requested or approved by the repository owner.

## Before Contributing

- Open an issue or contact the repository owner before starting substantial work.
- Keep all project-facing content in English.
- Do not submit generated, copied, or third-party content unless you have the right to contribute it.
- Do not add license terms that conflict with the proprietary license.
- Do not add unrelated files, internal notes, prompt files, or internal-only assets.

## Technical Guidelines

- Use HTML, CSS, and JavaScript for the website template.
- Do not convert the project to React or another application framework unless explicitly approved.
- Keep final website assets organized and relevant to the public project.
- Preserve responsive behavior across desktop, tablet, and mobile.
- Favor maintainable structure, accessible markup, and performance-conscious assets.

## Contribution Terms

By submitting a contribution, you confirm that you have the right to provide it and that the repository owner may use, modify, and incorporate it into this proprietary project. Submitting a contribution does not grant you or others any license to use this project outside the rights expressly allowed by the repository owner or GitHub's Terms of Service.

## Review

The repository owner may request changes, reject contributions, or close pull requests that do not fit the project scope, quality bar, or ownership requirements.
