# Hotelsort

Hotelsort is a proprietary static website project for hospitality, lodging, booking, and property-related brands. The project is intended for hotels, resorts, motels, inns, hostels, lodges, guesthouses, serviced apartments, and other accommodation businesses that need a polished front-page experience built with HTML, CSS, and JavaScript.

The repository will contain the final website files only, such as HTML, CSS, JavaScript, images, and public project documentation. Internal notes, prompt files, internal working artifacts, and unrelated working files are not part of the published project scope.

## About

Hotelsort focuses on a premium, responsive hospitality website experience. The planned template will support strong visual presentation, clear booking-oriented messaging, fast front-end delivery, and a professional structure suitable for real hotel, resort, lodging, and property brands.

## Project Scope

- Static front-page website template.
- HTML, CSS, and JavaScript only.
- Responsive layout for desktop, tablet, and mobile.
- Hospitality-focused visual direction and content.
- Public-facing project documentation.
